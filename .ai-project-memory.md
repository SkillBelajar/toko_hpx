# SaaS POS Toko HP - Project Memory

## 1. Ringkasan
SaaS Point of Sales khusus toko HP dengan arsitektur **Multi-tenant**. Satu instalasi melayani banyak toko;
data tiap toko terisolasi per tenant.

## 2. Core Logic
Sistem berlangganan bulanan namun dengan batasan **limit akumulasi total (seumur hidup)** untuk transaksi dan input IMEI.
Kuota Free: 30 transaksi total, 50 stok total. Pro: unlimited.

## 3. Fitur Psikologis
- **Peringatan Stok Mengendap (Aging Alert)** — unit tidak laku > X hari ditandai.
- **Pengingat Upsell di Kasir** — dorong aksesoris/produk margin tinggi saat checkout.
- **Sistem Buka/Tutup Shift (Modal Laci)** — selisih kas fisik vs sistem per kasir; mencegah kecurangan.

## 4. Tech Stack
Laravel 13, Octane (FrankenPHP), MySQL 8, Redis 7, Tailwind CSS 3.4, Alpine.js, Nginx, Docker Compose.

## 7. Arsitektur & Port
- `web` (nginx) → host **8080** → proxy ke `app:8000` (FrankenPHP Octane).
- `app`: build dari Dockerfile `dunglas/frankenphp:1-php8.3`.
- `db`: mysql:8, DB `tokohpx`, user `tokohpx` / pass `secret`, volume `mysql_data`.
- `redis`: redis:7-alpine, maxmemory 256mb.
- Env container: `.env.docker` (bare value, ada `APP_KEY`, `OCTANE_SERVER=frankenphp`).
- `.env` host di-mount ro ke container; `command` container jalankan `config:clear` dulu.

## 8. Konvensi Kerja
- JANGAN taruh `APP_KEY` hanya di `.env` — container env dari `.env.docker` menang; tanpa APP_KEY Octane crash loop.
- `proxy_set_header Host $http_host` di nginx, JANGAN `$host` — `$host` membuang port non-standar (8091), Laravel lalu men-generate aset `http://localhost/build/...` dan CSS/JS gagal dimuat (halaman tanpa style).
- `nginx/default.conf` hanya berisi `server {}` + `upstream`; jangan tambah `worker_processes`/`http {}` (nginx exit 1).
- Setelah edit route/controller di Octane: restart container app (`docker restart tokohpx_app`), `config:clear` saja tidak cukup.
- Tailwind versi 3 (postcss) — jangan pakai `@tailwindcss/vite` (v4) di proyek ini.
- `npm run dev` jangan dijalankan foreground; pakai `npm run build` untuk aset produksi.
